# ModelMate 平台部署

帮助平台零基础用户从准备数据和代码走到正式训练、监控与结果下载。每一步说清执行位置、实际路径/表单值和成功标志；已有信息从项目与当前会话提取，不让用户重复填写。已获授权的必要操作继续完成，缺少目标或会产生超出任务范围的影响时才问。

## 先选通道

1. **优先 SSH**：用户有运行中的 Notebook、SSH 入口与本机凭据时，读 [SSH 路线](references/ssh.md)，用 `scripts/modelmate_ssh.py` 建立或复用本机 profile。优先由助手执行远端准备与排障。
2. **无 SSH 也能部署**：开关不可用、网络不通或用户不使用 SSH，读 [非 SSH 路线](references/non-ssh.md)。通过 JupyterLab 文件面板和 Terminal 完成准备，不把 SSH 设为前置条件。
3. 两条通道共用 [部署与训练流程](references/workflow.md)：确认资源和持久化路径、准备数据、部署/修改/测试、页面创建作业、监控、导出与下载。
4. 有具体报错时读 [常见问题](references/troubleshooting.md)；产品行为或版本不明确时查 [来源与验证范围](references/sources.md)。按需要加载，不要求新用户阅读全套文档。

本机大数据/模型尚未上传时，按 [数据传输](references/data-transfer.md) 选择页面、SFTP或平台支持的存储客户端，包含没有SSH的路径。

正式训练默认沿平台页面创建。已验证部署中，Notebook SSH 不提供正式作业管理。若其他部署明确有官方管理接口，另核其文档和权限；不要凭 SDK 中存在 Trainer、镜像 CLI 或存储 AK/SK 就宣称能提交训练。

## 第一次接手

确认用户想做新训练、升级、恢复、仅测试还是取回结果。区分本地电脑、Notebook、正式训练容器与共享存储：Notebook 的设备和进程不是正式作业的设备和进程。用真实 `whoami`、`hostname`、`pwd` 和挂载信息建立映射，用户名从平台命令或实例核实，不拿网页登录姓名替代。

用户只需提供平台入口/当前会话、目标代码及任务；需要 SSH 时再取主机、端口、SSH 用户和凭据**本机路径**。不索取聊天中的私钥、口令或 token。首次连接有 `init`，不依赖预装 profile；后续直接复用已校验的本机配置。

公开安装包不携带任何使用者的真实 profile、连接日志或项目资料。项目信息保留在工作区或本机私有配置中；不要把个人挂载、模型、实验矩阵或卡数写成平台通用规则。

## 把任务做到可提交

- 先检查项目现有入口、配置和依赖，再改代码。兼容的镜像与运行时按项目确定，不盲目全局升级 torch/torch_npu。
- 新交付的正常启动设置有默认值。由助手根据已确认的实际资产和挂载准备配置，用户不必手填环境变量；高级覆盖保留并记录。平台 NPU 可见性由平台管理。
- 部署到新的明确源码目录；更新已有目录时校验版本、保留备份和改动记录。数据与结果放到已核实的可写持久化区域。
- `scripts/project_archive.py` 可打包代码、验证后解到新目录，或按明确列表导出小型结果包；不带入凭据与权重。
- 执行语法、导入与针对性测试；检查真实平台混合 argv（空存储参数、CONFIG 的大小写/等号/双 token/外层引号）。activation 后重新确认源码导入位置。
- 需要首次练习时，复制 `assets/starter/` 到独立项目。它生成64条数据并做小型真实 CPU 训练，不涉及外部模型下载。已有成熟项目无需强制跑示例。

## 页面提交与启动验收

在准备完成后给出具体提交表：源 Notebook、平台可选的启动文件、镜像、资源池、Worker/规格、数据与输出、正常参数/环境值。SSH 内绝对路径与网页选择器路径需要映射，不能直接等同。

有浏览器控制能力时按当前页面和用户授权协助；否则只把页面节点交给用户，不要求其代做已能通过 SSH 完成的准备。点击超时先核批次列表，避免重复创建。记录平台作业/批次 ID，再从启动日志固定本次运行与输出/日志目录。

Notebook 后续改码通常不更新已提交快照；共享存储改动仍可能影响活跃任务。修复需判断本次实际代码身份，不用“本地已改”证明远端生效。

## 监控、恢复和结果

监控固定到本次作业和路径，读取有限日志与已有监控器。分清平台状态、领取状态、实际计算推进和完成产物；注册文件、日志 mtime 或卡上有显存都不能单独证明训练存活。并行 ETA 按瓶颈与实际阶段估计，未知耗时待校准。

停止网页或 SSH 监控不代表训练停止。恢复明确目标与兼容身份，不自动选最新运行、删 claim/锁或重训。保留已经有效完成的产物。

结果包保留配置/源码身份、指标、必要原始输出、阶段日志和成本。排除权重不等于把其余全部递归打包；按项目索引或显式文件表控制数量与体积。下载前取得源摘要，下载后核对 SHA256，保留共享存储原件。

交付时讲清已完成动作、实际证据、当前阻塞和下一步。CPU/模拟测试、Notebook 小训练、正式作业创建与真实 NPU 训练分别报告。
